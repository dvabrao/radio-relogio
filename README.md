# Rádio Relógio do Daniel

Relógio de mesa para tablet e celular Android: hora, data e dia da semana com fontes e tamanho ajustáveis, rádios online com timer, alarmes (rádio ou bipe), brilho e modo noite, e tela sempre ligada.

Criado por Daniel Vale Abrão — dvabrao@gmail.com

O APK é gerado automaticamente em **Actions** e publicado em **Releases** a cada envio para `main`.
