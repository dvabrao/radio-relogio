Configurações

No computador: roda do mouse muda o tamanho; F = tela cheia; espaço = tocar/parar; setas ↑↓ = volume; ←→ = brilho.

Atalhos na tela: pinça com dois dedos muda o tamanho; arrastar no lado esquerdo muda o brilho; no lado direito, o volume. Toque rápido mostra os botões.

Modo noite automático

Dica: vermelho ou âmbar fraco atrapalham menos o sono.
